"Start extending to the west and south: same story, sightseeings more detailed, everything is realistic and accurate." Everything there is drawn GENERICALLY first by environment / streets / city. Landmark modules replace the generic output of their sight by the real thing; `src/world/layout.js` GROUPS claims make the generic modules skip what you draw.

## Rules that bite here (in addition to MARS-BRIEF.md)
* **No flags** (the Mariinsky, the palaces, ministries and New Holland normally carry them: omit; no flagpoles), no sirens / alarms, summer day, anime cel-shaded, realistic. Heights: street y = 0; canal water -2.7 ... -3.4.
* **Facade labels**: anything hung flat on a wall (shop signs, plates, plaques, ads, clocks) reserves its rectangle through `ctx.services.labels.reserve(...)` first (`docs/rules/LABELS-API.md`); plaques with real Russian text on your sights are welcome (legible, flush, standoff >= 1.5 cm).
* **Walls**: no cracks between your buildings and their neighbours (`docs/rules/FACADE-INTEGRITY.md`); run `npm run walls` if you touch footprint edges. **Road markings / plates / signs**: not yours (`streets/**`), do not draw road paint or traffic signs in landmark modules.
* **Road integrity**: nothing on a carriageway; paving you draw is clipped at `net.cover`; run `npm run roads` (needs your module in MODULES: the lead adds it; before that run `node tools/roads-furniture-audit.mjs --strict --near x,z,150`).
* Statues: the shared figure kit `src/world/lib/figures.js` (docs/FIGURES.md); the user judges monuments at 1-3 m. Everything repeated > ~40 times instanced. Budgets: <= ~300 k triangles per landmark module (New Holland may use ~400 k), build <= 1.5 s.
* Z-fighting is a bug class (`node tools/zfight.mjs`, target < 0.02 %). Shots: `node tools/shot.mjs --only environment,streets,city,<module> --cams "..." --out shots/<module>/a --t 20` (4 numbers = walking eye x,z,yaw,pitch; 5 = free x,y,z,yaw,pitch; yaw 0 north, 90 west, 180 south, -90 east); one screenshot job at a time (shared GPU, ~6 agents); LOOK at every PNG against the reference photos; include close-up (1-3 m), tourist street level, aerial and a long vista.
* Never run `git add` / `git commit` / `stash` / `checkout` / `reset` (the lead commits). Russian text only through Write / Edit (never shell heredocs). Do not touch `../100_3d_moscow_city`, `../101_3d_yakutsk`, `../sakuragaoka-station`. Keep your module loadable at all times.
* Final report < 30 lines: built / not built, services + OWNS_GROUPS, triangles / draw calls / build ms, files, problems, proposals for files you do not own.
