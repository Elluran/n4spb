## Rules that bite in this area
* **No flags** (Marble Palace, the Barracks, ministries, the Summer Palace area normally carry them: omit; no flagpoles at all). No sirens / alarms. Summer day.
* **Road integrity** (docs/AGENT-BRIEF.md): nothing on a carriageway, every drivable road asphalt. Memorial plaza, Mars Field alleys and Summer Garden paths are pedestrian surfaces: they are drawn by your module only where OSM says footway / pedestrian and they must be clipped at `net.cover` where they touch a carriageway. Run `npm run roads` before reporting.
* Heights: street y = 0; water -2.7 ... -3.4 (docs/research/west-canals-bridges.md); the Field is flat at y 0.
* The player must be able to walk everywhere a tourist walks (Field, Garden alleys, steps, plazas) and cannot walk through walls, statues, fence columns; the Summer Garden is open for the game (gates passable). Test with `tools/qa-walk.mjs` patterns or your own walk probe. People / traffic read your services (`ctx.services.landmarksMars` / `landmarksGarden`: benches, entrances, crowd spots, fences): publish them like `landmarksK`.
* Statues: use the shared figure kit `src/world/lib/figures.js` (docs/FIGURES.md); the user judges monuments at 1-3 m: no boxes.
* Budgets: a landmark module <= ~300 k triangles (Summer Garden fence + statues + trees may reach ~400 k with instancing), build <= ~1.5 s; trees / columns / balusters / urns / lamps instanced.
* Z-fighting is a bug class: `node tools/zfight.mjs --only <modules> --cams "..." --out shots/zfight/<you>`, target < 0.02 % noisy pixels in every frame showing your module.
* Never run `git add` / `git commit` / `stash` / `checkout` / `reset` (the lead commits). Russian text only through Write / Edit (never shell heredocs). Do not touch `../100_3d_moscow_city`, `../101_3d_yakutsk`, `../sakuragaoka-station`.
* Keep your module loadable at all times; write risky rewrites beside the old file and swap.
* Shots: `node tools/shot.mjs --only environment,streets,city,<module> --cams "..." --out shots/<module>/a --t 20` (header of tools/shot.mjs explains cameras; `4 numbers` = walking eye, `5 numbers` = free camera x,y,z,yaw,pitch; yaw 0 = north, 90 = west, 180 = south, -90 = east). One screenshot job at a time (shared GPU, other agents run too). Include a close-up (1-3 m), a tourist street-level view, an aerial and a long vista; LOOK at every PNG and compare with the reference photos.
